# CityWeather — погода по списку городов

Решение тестового задания на **Python** (только стандартные модули, без внешних пакетов).

## Задание

1. Загрузить список городов из файла **по ссылке** в память.
2. Для каждого уникального города получить данные через API
   `https://wttr.in/{City}?format=j1`.
3. Создать модель `WeatherData` с полями: **Город**, **Текущая температура (°C)**, **Страна**.
4. Вывести погоду по каждому городу: `Tokyo, Japan +18 °C`.
5. Сгруппировать города по странам и вывести для каждой страны:
   количество городов, среднюю, минимальную и максимальную температуру.

## Источники списка городов

Скрипт **сам скачивает** список городов по ссылке, ничего не хранит статически:

1. Основной источник: публичная ссылка облака Mail.ru
   `https://cloud.mail.ru/public/LWcw/kpMqFgztw`;
2. Резервный источник (тот же список):
   `https://gistpad.com/raw/vk-task-14`.

Если облако недоступно, автоматически берётся gistpad.

## Как это работает

| Шаг | Что делает | Где в коде |
|-----|------------|------------|
| 1. Загрузка городов по ссылке | `load_cities()` → облако через `load_cities_from_cloud()`, резерв — `gistpad` через `load_cities_from_url()`; `split_cities()` убирает дубликаты | `main.py:126` |
| 2. Скачивание из облака | `get_cloud_weblink_dispatch_url()` получает служебный адрес раздачи (`weblink_get`), к нему добавляется сегмент публичной ссылки — сервер редиректит на файл | `main.py:97` |
| 3. Запрос погоды | `fetch_weather_json()` обращается к `https://wttr.in/{City}?format=j1`, при недоступности HTTPS — повторяет по HTTP (JSON идентичен) | `main.py:178` |
| 4. Модель `WeatherData` | `dataclass` с полями `city`, `temperature_c`, `country` | `main.py:75` |
| 5. Разбор ответа | `parse_weather()` берёт `temp_C` и страну из `nearest_area` | `main.py:200` |
| 6. Вывод по городам | `print_city_weather()` форматирует `City, Country +18 °C` | `main.py:218` |
| 7. Сводка по странам | `summarize_by_country()` группирует через `defaultdict`, считает количество, среднее (sum/len), минимум и максимум | `main.py:227` |

### Детали по пунктам задания

* **Загрузка в память по ссылке.** Публичная ссылка облака — это адрес
  веб-приложения, а не файла: список файлов отдаётся через API
  `/api/v2/dispatcher` (поле `weblink_get`). Скрипт повторяет поведение
  браузера: получает служебный URL раздачи, склеивает с weblink-сегментом
  и скачивает файл. Города из текста файла извлекаются регулярным
  выражением (делители: перевод строки, запятая), дубликаты отбрасываются.
* **API wttr.in.** Точка `current_condition[0].temp_C` — текущая температура
  в °C; `nearest_area[0].country[0].value` — страна, определённая сервисом.
  Разбор — стандартным `json.loads`.
* **Все значения вычисляются кодом.** Средняя температура — `sum(temps)/count`,
  минимум и максимум — `min()` / `max()`, округление — `round()`; никакие
  данные не подставляются вручную.
* **Отказоустойчивость.** Два источника списка (облако → gistpad) и два
  протокола для wttr.in (HTTPS → HTTP). Сбои по отдельным городам не прерывают
  программу — в конце выводится список необработанных городов.

## Замечание по HTTPS

В условии указан адрес `https://wttr.in/{City}?format=j1`. Если HTTPS к
wttr.in заблокирован на уровне сети (исходящее соединение на :443 зависает),
код автоматически повторяет запрос по `http://wttr.in/{City}?format=j1` —
ответ JSON идентичен. На машинах с открытым доступом скрипт работает по HTTPS.
